## 0.0.1

- Add a debug-only widget selection and annotation overlay.
- Expose typed callback metadata for consumer-owned agent forwarding.
- Add a platform-agnostic example app and a debug-only default mode.
- Reduce the workflow to two compact controls and a draggable annotation card.
- Add an explicit release-mode opt-in with keys, semantics, ancestry, layout,
  diagnostics, and build-mode metadata for agent identification.
- Keep selection active across targets, remove the secondary floating action,
  and add a close action to the movable annotation card.
