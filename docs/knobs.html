Desy documentationKnobs
Registry input contract

Knobs are the portable input boundary.

Declare a component’s editable values once. Desy Bench uses that declaration for local controls; desy_genui derives the agent-facing JSON schema from it.

Choose the smallest useful value

  • string, choice, number, boolean, dateTime, and color model scalar values.
  • stringList models ordered text, such as labels, tags, or columns.
  • numberList models ordered numbers, with optional per-value bounds.
  • jsonValue models decoded JSON metadata: an object, array, string, number, or boolean. It is not a JSON-encoded string.
  • widgetInstance and widgetInstances compose real registered components; event reports intent back to the host.

Charts: parallel lists, consumer-owned view model

knobs: (k) => (
  title: k.string('title', initial: 'Weekly signal volume'),
  labels: k.stringList('labels', initial: const ['Mon', 'Tue', 'Wed']),
  values: k.numberList('values', initial: const [12, 18, 9], minimum: 0),
),
build: (context, knobs) => OrbitBarChartCard(
  title: knobs.title.value,
  data: OrbitChartDatum.zip(
    labels: knobs.labels.value,
    values: knobs.values.value,
  ),
),

The agent sends JSON arrays. The consumer alone defines the private OrbitChartDatum type and how to render it. Matching lengths are a component invariant.

What crosses the GenUI boundary

{
  "component": "orbit.component.bar-chart",
  "title": "New activations by channel",
  "labels": ["Search", "Invite", "Template"],
  "values": [38, 26, 19]
}

desy_genui produces an A2UI schema with items: { type: string } for stringList and items: { type: number } for numberList. It validates incoming lists before building the Flutter widget. JSON values are normalized and frozen at the boundary.

Use JSON intentionally

metadata: k.jsonValue(
  'metadata',
  initial: const {'source': 'workspace', 'fresh': true},
),

Use jsonValue for data whose shape is truly open. Prefer a scalar or one of the list knobs whenever the shape is known: it gives authors clearer controls and gives agents a narrower schema. A JSON value cannot declare widgets, callbacks, network calls, or executable code.

Keep the view, update the data

Scalar, list, and JSON knobs can bind to an A2UI data-model path. The component graph stays in place while only the affected consumer widget rebuilds.

{
  "component": "orbit.component.bar-chart",
  "labels": {"path": "/charts/weekly/labels"},
  "values": {"path": "/charts/weekly/values"}
}

{
  "version": "v0.9",
  "updateDataModel": {
    "surfaceId": "orbit-experiment",
    "path": "/charts/weekly/values",
    "value": [24, 31, 18]
  }
}

Bindings are for values, not component topology: child slots and events stay literal. The app still owns provider calls, authentication, refresh policy, and action permissions.

Local editing and persistence

Bench presents string and number lists as comma-separated inputs and JSON as a validated JSON editor. These edits are preview-session state only; they do not modify the immutable consumer registry or create a persisted manifest.
