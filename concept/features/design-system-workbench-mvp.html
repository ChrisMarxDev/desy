ConceptPlanned features

Recommended MVP

Atoms, constrained canvas, derived skill.

Prove that a Flutter team can define its visual vocabulary, compose a screen with it, and hand an agent an accurate skill generated from that same source.

Reason for existing

User value

Teams can explore a real screen instead of isolated widgets while preserving system rules.

Why this slice

It is materially simpler than a full design tool and more useful to agents than a conventional catalogue.

Success signal

An agent uses the derived skill to reproduce a saved builder screen using approved atoms and components only.

Scope

Included

  • Registry for design tokens/atoms and components
  • Standard layout primitives: page, section, row, column, stack, scroll, grid
  • Hard slots for page chrome, component content, actions, icons, and states
  • Drag, drop, reorder, select, duplicate, and edit allowed properties
  • Live Flutter canvas: theme, device, locale, text scale, state
  • System-wide skill generator and saved-screen examples

Acceptance boundary

  • Define 20 atoms and 10 components in one package
  • Compose a realistic checkout or settings screen without custom styling
  • Prevent unsupported slot/property combinations in the UI
  • Export a skill containing all registered atoms/components and examples
  • Implement the screen with an agent and validate its widget/golden output

Non-goals

  • Freeform pixel positioning as the default layout model
  • Business logic, navigation wiring, or a complete no-code app builder
  • Figma replacement or sync
  • Manual prose documentation that duplicates registry data
  • Autonomous agent source edits without normal review and verification

Implementation sketch

Dart registry → atom/component schemas → constrained canvas manifest → Flutter renderer → system SKILL.md → widget + golden verification

Each component schema names properties and slots. The canvas stores a tree of component IDs, property values, and children by named slot. A renderer converts that tree to live Flutter; the skill exporter traverses the same registry, so documentation cannot drift from the available system.
