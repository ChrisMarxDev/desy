Make the real system legible before making it agentic.

Ranked by durable design-system value per unit of complexity. Shipped catalogue and Measurement board foundations are deliberately excluded.

Ranking rule

Prioritise primitive vocabulary and evidence that make real Flutter components consistent. Agent acceleration follows; features that create a parallel design system or app builder move down.

Impact and complexity use a 1–5 scale.
