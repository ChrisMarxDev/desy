Optional protocol experiment

Run local Codex as a constrained GenUI driver.

Prove a self-contained desktop app can launch Codex app-server as a child process, ask it for schema-constrained A2UI operations, and render those operations through Flutter GenUI.

Boundary

No agent runtime, A2A server, ACP implementation, provider key, or new Desy contract. This is Codex app-server JSON-RPC over stdio plus an adapter emitting canonical A2UI messages.

Package split

codex_app_server is pure Dart process/JSON-RPC plumbing. genui_codex maps a GenUI request to a Codex turn, then constrained JSON to A2UI.

Scope

Dart VM desktop only. The driver defaults to read-only work and rejects invalid model output. Flutter Web, Android, and iOS remain unsupported.

Wire map

Conversation / ChatMessage → Codex turn/start (JSON-RPC JSONL)
Codex final structured output → A2UI v0.9 messages → SurfaceController

The catalog capability and compact instruction are model context, not a wire protocol. A2A is deliberately absent.
